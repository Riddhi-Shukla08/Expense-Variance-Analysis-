# Expense-Variance-Analysis-
Analyzed budgeted vs actual expenses, calculated variance and variance percentage, identified material gaps, and created an interactive Power BI dashboard for monthly and category-wise expense analysis.

## 📌 Project Overview

Expense Variance Analysis is a data analysis project that compares budgeted expenses with actual expenses.

The project calculates expense variance and variance percentage to identify differences between planned and actual spending. The analysis is presented through an interactive Power BI dashboard.

## 🎯 Objective

The main objectives of this project are:

- Compare Budget vs Actual Expenses
- Calculate Expense Variance
- Calculate Variance Percentage
- Analyze expenses by category
- Analyze monthly expense trends
- Identify material gaps between budget and actual expenses
- Present insights through an interactive dashboard

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- DAX

## 📂 Dataset

The dataset contains expense information across different months and expense categories.

### Main Columns

- Month
- Expense Category
- Budget
- Actual
- Variance
- Variance %
- Gap Status

## 🧮 Calculations

### Variance

```text
Variance = Actual - Budget
Variance Percentage
Variance % = Variance / Budget × 100
Material Gap

A variance of 10% or more is flagged as a Material Gap.
